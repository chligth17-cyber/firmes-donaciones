# FIRMES — Campaña de apoyo estudiantil

Sitio web de la campaña estudiantil FIRMES, construido con HTML, CSS y JavaScript sin dependencias de ejecución.

## Contenido

- Presentación de la campaña
- Descripción de FIRMES
- Proceso de apoyo en tres pasos
- Compromiso de anonimato y privacidad
- Sección preparada para enlazar el formulario de solicitud
- Enlace al Instagram oficial: [@firmes.donaciones](https://www.instagram.com/firmes.donaciones/)

## Uso local

Abre `index.html` directamente en un navegador o utiliza cualquier servidor estático local.

El botón de solicitud está preparado con un ancla para conectarlo posteriormente al formulario correspondiente.
